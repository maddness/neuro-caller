# Решение проблем Voximplant

## Ошибка 403 - Forbidden при исходящих звонках

**Симптомы:**
```
Call failed: 403 - Forbidden
```

**Причина:** Номер телефона не настроен для исходящих звонков или недостаточно средств на балансе.

### Решение:

#### 1. Пополните баланс аккаунта

1. Перейдите в панель управления: https://manage.voximplant.com
2. Откройте **Billing** → **Balance**
3. Нажмите **Add funds**
4. Пополните баланс минимум на **10-20 EUR** (этого хватит на несколько сотен тестовых звонков)

**Важно:** Без положительного баланса исходящие звонки работать не будут!

#### 2. Настройте Caller ID для номера

1. Перейдите в **Numbers** → **My Phone Numbers**
2. Найдите ваш номер `+74999384362`
3. Кликните на номер для открытия настроек
4. В секции **Outbound Calling**:
   - Включите **"Allow outbound calls"**
   - Убедитесь, что номер **verified** (подтвержден)
5. Сохраните изменения

#### 3. Проверьте привязку номера к приложению

1. В **Numbers** → найдите `+74999384362`
2. Проверьте секцию **Bound to**:
   - Должно быть указано приложение `neeno-caller`
   - Если нет - привяжите номер к приложению

#### 4. Проверьте настройки Routing Rule

1. Перейдите в **Routing** → **Rules**
2. Найдите правило `outbound_calls` (ID: 3769281)
3. Убедитесь что:
   - Правило **активно** (enabled)
   - В секции **Caller ID** указан номер `+74999384362`
   - Pattern: `.*` (любой номер)
   - Assigned scenario: `ai_recruiter`

#### 5. Альтернатива: Использовать тестовый номер

Если вы не хотите пополнять баланс прямо сейчас, можете использовать бесплатный тестовый режим:

Измените в сценарии вызов:
```javascript
// Было:
currentCall = VoxEngine.callPSTN(data.phoneNumber, '74999384362');

// Станет (для теста):
currentCall = VoxEngine.callConference(
    data.phoneNumber,
    'testconf',
    {},
    {}
);
```

Это создаст тестовую конференцию вместо реального звонка (бесплатно).

## Проверка после настройки

После выполнения шагов 1-4 запустите тестовый звонок:

```bash
python voximplant/make_call_vox.py +79979569483
```

Ожидаемый результат в логах:
```
=== Call Connected ===
```

Если звонок прошел успешно - вы услышите голосовое приветствие на телефоне `+79979569483`.

## Дополнительные проблемы

### Ошибка "OpenAI is not defined"

**Решение:** Используйте упрощенный сценарий `recruitment_bot_simple.js` для первого теста. После успешного звонка вернемся к интеграции с OpenAI Realtime API.

### Ошибка "Module not found: OpenAI.js"

**Решение:** Удалите строку `const OpenAI = require('OpenAI');` из сценария. В VoxEngine OpenAI доступен глобально.

### Ошибка "Logger.Priority is undefined"

**Решение:** Используйте строковые литералы вместо `Logger.Priority.ERROR`:
```javascript
// Неправильно:
Logger.write('Error', Logger.Priority.ERROR);

// Правильно:
Logger.write('Error', "ERROR");
```
