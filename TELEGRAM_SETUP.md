# Настройка Telegram уведомлений

Система может отправлять уведомления в Telegram о каждом этапе обработки аудиозаписей.

## Создание Telegram бота

### Шаг 1: Создание бота через BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Введите имя вашего бота (например: "USB Recorder Notifier")
4. Введите username бота (например: "usb_recorder_bot")
5. BotFather пришлет вам **токен бота** - сохраните его!

Пример токена: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

### Шаг 2: Получение Chat ID

Есть несколько способов узнать ваш Chat ID:

#### Способ 1: Через @userinfobot

1. Найдите в Telegram бота [@userinfobot](https://t.me/userinfobot)
2. Отправьте ему любое сообщение
3. Бот ответит вашими данными, включая **Chat ID**

#### Способ 2: Через API

1. Отправьте любое сообщение вашему боту
2. Откройте в браузере:
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
3. Найдите в ответе поле `"chat":{"id": 123456789}`

## Настройка системы

### Через .env файл (рекомендуется)

1. Скопируйте пример конфигурации:
   ```bash
   cp .env.example .env
   ```

2. Отредактируйте `.env`:
   ```env
   # Telegram Notifications
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   TELEGRAM_CHAT_ID=123456789
   TELEGRAM_ENABLED=true
   ```

3. Запустите систему как обычно:
   ```bash
   python main.py monitor
   ```

### Через аргументы командной строки

```bash
python main.py monitor \
  --telegram-token "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz" \
  --telegram-chat "123456789"
```

### Отключение уведомлений

Если нужно временно отключить Telegram уведомления:

```bash
# В .env
TELEGRAM_ENABLED=false

# Или через CLI
python main.py monitor --telegram-enabled false
```

## Тестирование

Проверить работу уведомлений можно запустив тестовый скрипт:

```bash
python -m src.telegram_notifier
```

Это отправит серию тестовых сообщений в ваш Telegram.

## Использование в группах

Если хотите получать уведомления в группу:

1. Создайте группу в Telegram
2. Добавьте вашего бота в группу
3. Сделайте бота администратором
4. Получите Chat ID группы (начинается с `-`, например `-123456789`)
5. Укажите этот Chat ID в настройках

## Решение проблем

### Бот не отправляет сообщения

1. **Проверьте токен бота** - скопировали ли вы его полностью?
2. **Проверьте Chat ID** - правильно ли указан?
3. **Запустите бота** - отправьте `/start` вашему боту в Telegram
4. **Проверьте логи** - посмотрите логи системы на наличие ошибок

### Бот создан, но не отвечает

Убедитесь что:
- Бот не заблокирован
- Вы отправили ему хотя бы одно сообщение (например `/start`)
- Токен скопирован правильно

### Ошибка "Chat not found"

Это означает что:
- Chat ID указан неверно
- Вы не начали диалог с ботом (отправьте `/start`)
- Бот был удален из группы (если используете группу)

## Безопасность

**ВАЖНО:**
- Не публикуйте токен бота в публичных репозиториях
- Не передавайте токен третьим лицам
- Используйте `.env` файл (который в `.gitignore`)
- Если токен скомпрометирован, создайте нового бота через BotFather

## Дополнительные возможности

### Множественные получатели

Чтобы отправлять уведомления нескольким людям:

1. Создайте группу
2. Добавьте всех нужных людей
3. Добавьте бота в группу
4. Используйте Chat ID группы

### Форматирование сообщений

Система использует HTML форматирование:
- `<b>текст</b>` - жирный
- `<code>текст</code>` - моноширинный шрифт
- `<i>текст</i>` - курсив

## Стоимость

Telegram Bot API **бесплатен** для использования. Нет ограничений на количество сообщений.
